# DADA-TUDA Mobile App

Kotlin Multiplatform mobile app for the DADA-TUDA product.

## What it does
- Demonstrates shared logic across mobile targets.
- Shows product-oriented app structure instead of a one-off demo.
- Useful as proof of full-stack breadth beyond backend work.

## Stack
Kotlin Multiplatform, Compose Multiplatform, dependency injection, networking.

## Why it matters
This helps the profile read as a real engineer who can ship across platforms and not only build APIs.
